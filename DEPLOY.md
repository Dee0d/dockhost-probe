# Как выложить этот сайт на dockhost.ru (инструкция для новичка)

**Docker на компьютер ставить не нужно.** Нужны только браузер, бесплатный аккаунт на GitHub
и немного денег на балансе Dockhost (хватит 200–300 ₽).

Коротко вся схема: файлы кладём на GitHub → Dockhost сам собирает из них «коробку» (образ) →
запускает её (контейнер) → выдаёт адрес сайта.

---

## Шаг 1. Аккаунт на GitHub

GitHub — это облачная папка для файлов проекта.

1. Зарегистрируйтесь на github.com.
2. Нажмите **New repository**.
3. Имя: `dockhost-probe`, тип **Public**, галочки про README не ставьте.
4. **Create repository**.

## Шаг 2. Загрузите файлы (перетаскиванием, без команд)

1. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
2. Откройте папку проекта на компьютере, выделите **всё содержимое** (Ctrl+A).
3. Перетащите файлы в окно браузера.
4. Внизу напишите «первая загрузка» и нажмите **Commit changes**.

⚠️ Важно: `Dockerfile`, `package.json` и папка `src` должны быть видны сразу на главной странице
репозитория. Если они оказались внутри ещё одной папки — сборка их не найдёт.
Папку `node_modules` загружать не нужно.

## Шаг 3. Токен доступа GitHub

Токен — ключ, который можно дать другому сервису вместо пароля.

Аватар → **Settings** → внизу **Developer settings** → **Personal access tokens** →
**Tokens (classic)** → **Generate new token (classic)** → галочка **repo** → **Generate token**.

Скопируйте строку `ghp_...` сразу: второй раз её не покажут.

## Шаг 4. Аккаунт Dockhost

1. Зарегистрируйтесь на my.dockhost.ru, подтвердите почту.
2. Пополните баланс (минимальный сайт — около 100 ₽ в месяц, оплата почасовая).
3. Включите двухфакторную аутентификацию.

## Шаг 5. Создайте проект

**Проекты → Создать.** Имя латиницей, например `probe`.
Ресурсы: **1 CPU, доля 10%, память 256 MiB** — для простого сайта этого хватает.

## Шаг 6. Подключите репозиторий

**Проект → Репозитории Git → Добавить:**

- URL: ссылка с GitHub (зелёная кнопка **Code** → вкладка HTTPS), вида
  `https://github.com/ваш-логин/dockhost-probe.git`
- Ветка: `main`
- Логин: ваш логин GitHub, пароль: **токен** из шага 3
- Путь к Dockerfile: `./Dockerfile`, контекст сборки: корень
- Включить **автоматическую сборку при push**

## Шаг 7. Соберите образ

**Репозитории Git → Пайплайны → Собрать.** Ждём 1–3 минуты и статус «Успешно».
Если ошибка — прокрутите лог до первой строки со словом `error`.

## Шаг 8. Запустите контейнер

**Контейнеры → Создать:**

- Образ: тот, что собрал пайплайн
- Реплики: 1, ресурсы: 1 CPU / 10% / 256 MiB
- **Порты: добавить 80/TCP** (это «дверь», которую слушает сайт)

Ждём статус **Running** и заглядываем в «Логи» — там должны быть строчки от nginx.

## Шаг 9. Адрес сайта

**Домены → Добавить** → возьмите бесплатный адрес вида `имя.dockhost.ru`
(либо впишите свой домен и пропишите у регистратора A-запись на адрес из панели + выпустите
бесплатный сертификат Let's Encrypt).

**Маршруты → Создать:** домен — ваш, путь — `/`, сервис — ваш контейнер, порт — `80/TCP`.
Включите переадресацию с HTTP на HTTPS.

## Шаг 10. Проверка и обновления

Откройте домен. Видите страницу с зелёной плашкой — готово.

Чтобы что-то изменить: на GitHub откройте файл → карандашик → правьте → **Commit changes**.
Dockhost сам пересоберёт сайт за пару минут.

---

## Что внутри файлов

| Файл | Зачем |
|---|---|
| `Dockerfile` | Рецепт сборки: собрать сайт через Node.js, положить результат в nginx |
| `nginx.conf` | Настройки раздачи страниц: сжатие, проверка `/healthz`, работа внутренних ссылок |
| `.dockerignore` | Что не отправлять на сборку (`node_modules`, `.env` и прочее лишнее) |
| `dockhost.yaml` | Необязательно: описание проекта текстом для Dockhost CLI |

## Частые проблемы

- **Сборка упала** — проверьте, что `Dockerfile` лежит в корне репозитория, а `node_modules` не загружен.
- **Контейнер перезапускается** — смотрите «Логи». Для nginx обязателен `daemon off;` (уже прописан).
- **Running, но сайт не открывается** — не открыт порт 80/TCP или не создан маршрут.
- **Свой домен молчит** — DNS обновляется до нескольких часов, подождите.
- **Видно старую версию** — кеш браузера, обновите через Ctrl+F5 (Mac: Cmd+Shift+R).
- **Как перестать платить** — остановите или удалите контейнер, либо удалите проект целиком.

## Если захотите проверять сборку локально (не обязательно)

Это понадобится только когда освоитесь. Нужен установленный Docker Desktop:

```bash
docker build -t probe .
docker run --rm -p 8080:80 probe
# откройте http://localhost:8080
```
